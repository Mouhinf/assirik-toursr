# Plan : Intégration EmailJS pour Notifications par Email des Formulaires

## Objectif
Envoyer automatiquement un email à `assiriktours@gmail.com` à chaque soumission de formulaire (Voyages, Immobilier, Nettoiement, Contact) en utilisant EmailJS — sans backend supplémentaire.

## Architecture
```
Formulaire → Appwrite (stockage) + EmailJS (notification email)
                                      ↓
                              assiriktours@gmail.com
```

## Étapes d'implémentation

### 1. Configuration EmailJS (manuel, côté utilisateur)
- Créer un compte sur https://www.emailjs.com/ (gratuit : 200 emails/mois)
- Ajouter un service email (Gmail) → obtenir `SERVICE_ID`
- Créer 4 templates d'email (un par département) → obtenir `TEMPLATE_ID` pour chacun
- Récupérer la `PUBLIC_KEY` depuis le dashboard

### 2. Installation EmailJS SDK
- Ajouter `@emailjs/browser` dans `src/frontend/package.json`
- Créer `src/frontend/src/lib/emailService.ts` avec :
  - Fonction `sendEmail(templateId, formData)` générique
  - Templates de données pour chaque département
  - Gestion d'erreur silencieuse (ne pas bloquer la soumission)

### 3. Intégration dans les formulaires
Modifier les handlers `handleSubmit` de chaque page :
- **Contact.tsx** : Envoyer email après soumission Appwrite réussie
- **Voyages.tsx** : Idem, avec données enrichies (destination, budget, etc.)
- **Immobilier.tsx** : Idem, avec données immobilières
- **Nettoiement.tsx** : Idem, avec données nettoyage

Pattern d'intégration :
```typescript
// Après onSuccess de la soumission Appwrite :
sendEmail("TEMPLATE_ID", {
  to_name: "Équipe Assirik Tours",
  from_name: form.nom,
  from_email: form.email,
  from_phone: form.telephone,
  message: form.message,
  department: "Voyages",
  submitted_at: new Date().toLocaleString("fr-FR"),
}).catch(() => console.warn("Email notification failed"));
```

### 4. Variables d'environnement
Ajouter dans `src/frontend/.env` :
```
VITE_EMAILJS_PUBLIC_KEY=your_public_key
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_VOYAGES=template_id_voyages
VITE_EMAILJS_TEMPLATE_IMMOBILIER=template_id_immobilier
VITE_EMAILJS_TEMPLATE_NETTOIEMENT=template_id_nettoiement
VITE_EMAILJS_TEMPLATE_CONTACT=template_id_contact
```

### 5. Templates EmailJS (à créer dans le dashboard)
Chaque template aura ce format :
```
Sujet : Nouvelle demande {{department}} - {{from_name}}

Bonjour,

Une nouvelle demande a été soumise sur le site Assirik Tours :

📋 Département : {{department}}
👤 Nom : {{from_name}}
📧 Email : {{from_email}}
📞 Téléphone : {{from_phone}}
📅 Date : {{submitted_at}}

💬 Message :
{{message}}

---
Ceci est un email automatique, ne pas répondre directement.
```

### 6. Tests
- Tester chaque formulaire individuellement
- Vérifier la réception des emails
- Vérifier que la soumission Appwrite fonctionne toujours
- Tester le cas où EmailJS échoue (ne doit pas bloquer)

## Coût
