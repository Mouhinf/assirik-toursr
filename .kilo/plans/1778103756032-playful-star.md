# Plan : Migration Backend ICP → Appwrite + Déploiement Netlify

## Objectif
Remplacer le backend Motoko (ICP) par Appwrite (gratuit) et déployer le frontend sur Netlify avec votre nom de domaine existant.

## Architecture cible
```
Frontend (React/Vite) → Netlify (votre domaine)
                            ↓
Backend (API REST) → Appwrite Cloud (gratuit)
```

## Étapes de migration

### 1. Configuration Appwrite
- Créer un projet Appwrite Cloud gratuit
- Créer la collection `demandes` avec les attributs :
  - `id` (string, auto-généré par Appwrite)
  - `nom` (string)
  - `email` (string)
  - `telephone` (string)
  - `message` (string)
  - `departement` (enum: "voyages" | "immobilier" | "nettoiement" | "contact")
  - `statut` (enum: "nouveau" | "traite")
  - `created_at` (datetime)
- Configurer les permissions de collection pour permettre l'écriture publique et la lecture protégée
- Activer l'authentification Email/Password pour l'interface admin

### 2. Migration du frontend
- Supprimer les dépendances ICP (`@dfinity/*`, `@icp-sdk/core`)
- Installer `appwrite` (SDK officiel)
- Créer un client Appwrite configuré avec les variables d'environnement
- Remplacer les appels au backend ICP par les appels Appwrite
- Mettre à jour les formulaires de soumission (4 services)
- Créer/mettre à jour la page admin avec la console Appwrite ou une interface custom

### 3. Interface d'administration
Deux options :
- **Option A** : Utiliser la console Appwrite intégrée (gratuite, très intuitive)
- **Option B** : Créer une page admin custom dans le frontend avec auth Appwrite

### 4. Déploiement Netlify
- Configurer `netlify.toml` à la racine
- Ajouter les variables d'environnement Appwrite dans Netlify
- Connecter le repo GitHub à Netlify pour le déploiement automatique
- Configurer votre nom de domaine existant

### 5. Nettoyage
- Supprimer les fichiers backend Motoko (`src/backend/`)
- Supprimer la configuration ICP (`dfx.json`, `mops.toml`, `mops.lock`)
- Mettre à jour `package.json` root
- Mettre à jour `AGENTS.md` avec les nouvelles commandes

## Structure finale du projet
```
assirik-toursr/
├── src/frontend/          # Application React
│   ├── src/
│   │   ├── components/    # Header, Footer, Layout, UI
│   │   ├── pages/         # Home, Voyages, Immobilier, Nettoiement, APropos, Contact, Admin
│   │   ├── lib/           # Client Appwrite

```
